Ao final do capítulo, cada país marcado como visitado atualiza três lugares da tela ao mesmo tempo: o número, a barra e as bandeiras.

E você não vai escrever nenhuma linha para atualizar a tela. Quem faz isso é o Angular, graças aos signals.

💡
A ideia

O placar do estádio

🏟️

Ninguém no estádio conta os gols de cabeça. Todo mundo olha para o placar. Quando sai um gol, alguém muda o placar uma vez, e todos os torcedores veem o número novo, sem ninguém avisar cada um.

Um signal é o placar: um valor guardado num lugar só. A tela é a torcida: ela olha para o signal e se atualiza quando ele muda.

Aprofundando: o computed recalcula sempre?

Não. Ele é preguiçoso e memoriza o resultado: só recalcula quando alguém lê o valor e algum signal de que ele depende mudou. Se ninguém olhar, não gasta processamento.

🛠️
Mão no código

Construindo o contador

1. Criar o signal2. Derivar com computed3. Mostrar e atualizar

Na classe do componente, a porcentagem nasce do número de visitados. Repare que ela é uma fórmula, não um valor guardado:

export class Contador {
  visitados = signal(3);1
  pct = computed(() => this.visitados() / 195 * 100);2
  visitar() {
    this.visitados.update(n => n + 1);3
  }
}
1signal(3) cria a caixinha com o valor inicial.
2computed lê visitados(), com parênteses: é assim que se lê um signal.
3update calcula o valor novo a partir do atual.
✅ Na tela: clique em “Visitar” e veja a porcentagem mudar junto com o número.

Armadilhas

Os erros que você vai ver

Esqueceu os parênteses no template? Em vez do número, aparece isto na tela:

[Signal: 3]

Para ler um signal, sempre visitados(), com parênteses.
