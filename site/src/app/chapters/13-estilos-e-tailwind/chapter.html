Até aqui, cada componente do Passaporte tinha um arquivo CSS cheio de regras escritas à mão. Neste capítulo, o cabeçalho e a lista de países trocam o CSS por classes do Tailwind, escritas direto no HTML, e a lista vira uma grade de duas colunas nas telas maiores.

Ao final, você vai entender como o Angular isola o CSS de cada componente, quando usar CSS próprio e quando usar o Tailwind, e como acrescentar ícones.

Você pode esculpir uma casinha num bloco de madeira, do jeito que quiser, ou montar com peças de Lego prontas: uma para a parede, uma para a janela, uma para o telhado. Esculpir dá liberdade total; montar é muito mais rápido e sempre combina.

Escrever CSS à mão é esculpir. O Tailwind é a caixa de peças: cada classe, como p-4 (espaço interno) ou rounded-xl (cantos arredondados), faz uma coisa pequena, e você monta o visual juntando classes.

O CSS de cada componente fica nele

No , você viu que o CSS de um componente só vale para ele. O truque: o Angular marca cada elemento do componente com um atributo único e reescreve as regras do CSS para valer só para elementos com esse atributo. Isso se chama encapsulamento.

Tailwind: classes utilitárias

O Tailwind é uma biblioteca de CSS com milhares de classes pequenas, as utilitárias. Leia as do cartão de país: flex items-center gap-3 (os itens lado a lado, centralizados, com espaço entre eles), rounded-xl (cantos), border border-stone-200 (borda cinza), bg-white px-4 py-3 (fundo branco e espaço interno) e shadow-sm (sombra leve).

Prefixos mudam quando a classe vale:

  • hover:text-white: só quando o mouse está em cima.
  • sm:grid-cols-2: duas colunas só a partir de telas pequenas para cima (640 px). No celular, uma coluna só.

Ícones

O globo do cabeçalho é um SVG escrito direto no template: um desenho feito de linhas, que fica nítido em qualquer tamanho e pega a cor do texto com stroke="currentColor".

O aria-hidden="true" diz aos leitores de tela que o ícone é decoração. Para muitos ícones, existem bibliotecas prontas, como o Lucide e o Material Symbols, ambas gratuitas.

Os dois convivem bem, e o Passaporte usa os dois: o cabeçalho e a lista estão em Tailwind; o placar e o país em destaque continuam com CSS próprio. Tailwind acelera o dia a dia e mantém o visual consistente; CSS próprio é melhor para efeitos complexos, como animações elaboradas. Num projeto real, a equipe escolhe um caminho principal. O Tailwind traz um reset que zera os estilos padrão do navegador: títulos perdem o tamanho e o negrito, listas perdem as bolinhas. É de propósito: assim nada vem com aparência inesperada. Como sair: dê o estilo explicitamente, com classes como text-2xl font-extrabold ou no CSS do componente.

O Tailwind gera só as classes que encontra inteiras no seu código. Uma classe montada com + só existe quando o app roda, e aí é tarde: ela não foi gerada. Como sair: escreva as classes completas e escolha entre elas.

No CSS, @apply bg-passaporte pede ao Tailwind as regras de uma classe que ele não conhece. Ela só existiria se você criasse uma cor chamada passaporte, que é justamente o assunto do próximo capítulo. Como sair: use uma classe que existe, ou crie a cor como token.
