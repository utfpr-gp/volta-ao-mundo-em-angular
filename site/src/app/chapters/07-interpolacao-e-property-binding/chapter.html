Nome, capital, população, a imagem da bandeira e até o estado do botão saem de um objeto na classe. Ao final do capítulo, você vai saber levar qualquer dado da classe para a tela, como texto ou como propriedade de um elemento.

Sabe aquelas cartas que chegam com o seu nome no meio do texto? Quem escreveu não fez uma carta para cada pessoa: fez um modelo com espaços marcados, como "Olá, ___", e uma planilha com os dados. A impressora junta os dois.

O template é o modelo com os espaços, e a classe é a planilha. A diferença é que, no Angular, quando um dado da classe muda, a tela é atualizada para mostrar o valor novo.

Ligar um dado da classe a um lugar do template se chama binding. Neste capítulo, o dado sempre desce, da classe para a tela. São duas formas, e você usa as duas no mesmo componente:

Interpolação: {{ }} para mostrar texto

As chaves duplas são a interpolação. Dentro delas vai uma expressão, como country.name, e o resultado aparece como texto naquele lugar. Pode ter interpolação no meio de uma frase, como em Capital: {{ country.capital }}. A expressão pode fazer contas simples, como {{ country.population / 1000000 }}, mas a regra de ouro é manter o template simples: lógica de verdade fica na classe.

Property binding: [ ] para dar valor a uma propriedade

Os colchetes são o property binding: em [src]="country.flagUrl", a propriedade src da imagem recebe o valor de country.flagUrl. Sem os colchetes, src="country.flagUrl" seria só um texto, e o navegador tentaria abrir um arquivo chamado literalmente "country.flagUrl".

O property binding serve para qualquer propriedade de um elemento: [alt], [disabled], [title], [href]. Repare em [disabled]="country.visited": o valor é um boolean, e não um texto. É por isso que, para propriedades que não são texto, os colchetes são o caminho.

Qual usar?

Você quer… Use Exemplo
mostrar um valor como texto interpolação <h2>{{ country.name }}</h2>
dar valor a uma propriedade de um elemento property binding <img [src]="country.flagUrl">
ligar ou desligar algo com verdadeiro ou falso property binding <button [disabled]="country.visited">

No HTML, você escreve atributos (src="..."). Quando o navegador lê a página, ele cria um objeto para cada elemento, com propriedades. Na maioria dos casos os nomes batem, mas não sempre: o atributo class vira a propriedade className, por exemplo. O [ ] do Angular liga a propriedade do objeto, e não o atributo.

Para os raros casos em que só existe o atributo, como aria-label em alguns elementos, o Angular tem o [attr.aria-label]="...". Você vai usar isso no capítulo de acessibilidade.

No template, você escreveu {{ country.nome }}, mas a propriedade se chama name. O Angular confere o template com o TypeScript, então o erro aparece antes de o app rodar, com a lista de propriedades que existem. Como sair: use o nome exato que está na classe.

"Não dá para ligar a scr, porque ela não é uma propriedade conhecida de img." Foi um erro de digitação: o certo é src. O mesmo erro aparece se você tentar ligar uma propriedade que o elemento realmente não tem. Como sair: confira o nome da propriedade.

Com src="country.flagUrl", sem colchetes, não há binding: o navegador procura um arquivo chamado "country.flagUrl", não acha, e mostra o ícone de imagem quebrada. Como não é um erro de código, o terminal fica em silêncio. Como sair: ponha os colchetes, [src].
