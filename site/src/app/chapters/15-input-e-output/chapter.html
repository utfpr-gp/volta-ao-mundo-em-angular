Por fora, quase nada muda. Por dentro, é a primeira vez que dois componentes do Passaporte trocam dados. Ao final do capítulo, você vai saber passar dados de pai para filho e avisar o pai do que aconteceu no filho.

A cozinha entrega o prato ao garçom, e o garçom leva à mesa. Se o cliente pedir para trocar o prato, o garçom não vai para o fogão cozinhar outro: ele avisa a cozinha, e a cozinha decide o que fazer e manda o prato novo.

A lista é a cozinha, dona dos dados. O cartão é o garçom: recebe o país pronto pelo input() e, quando algo acontece, avisa pelo output(). Quem muda os dados é sempre o dono deles.

O filho: o que ele recebe e o que ele avisa

input.required<Country>() declara um input obrigatório: o cartão não faz sentido sem um país. input(0) declara um opcional, com valor padrão. Um input é um signal só de leitura: no template, você lê com parênteses, {{ country().name }}, e o cartão nunca muda o valor; só quem passa o valor pode mudá-lo.

O pai: como ele usa o filho

Repare que é tudo o que você já sabe. [country]="country" é um property binding, como o [src] do capítulo 7, agora numa propriedade do seu componente. (toggled)="toggleVisited($event)" é um event binding, como o (click) do capítulo 8; o $event é o que o filho mandou no emit, aqui o código do país.

O toggleVisited segue a regra dos signals: cria um array novo, trocando só o país clicado por uma cópia com visited invertido. O cartão recebe esse país novo pelo input, e a tela acompanha.

Antes dos signals, inputs e outputs eram declarados com decorators: @Input() country!: Country; e @Output() toggled = new EventEmitter<string>();. Ainda funcionam, mas o jeito atual é input() e output(): o input vira um signal, combina com computed e não precisa do ! para enganar o TypeScript. O próprio Angular tem uma migração automática do jeito antigo para o novo.

Você usou <app-country-card /> sem o [country]. Como o input é required, o Angular não deixa: o cartão não teria o que mostrar. Como sair: passe o valor.

Um input é um signal: {{ country.name }} não funciona. Como sair: {{ country().name }}.

O cartão tentou fazer this.country.set(...). Um input só pode ser mudado por quem o passa: o filho só lê. Como sair: avise o pai com um output, e deixe o pai mudar os dados.

Com (toggle)="..." no pai, mas o output chamado toggled no filho, o Angular escuta um evento que nunca acontece. Não há erro, porque poderia ser um evento comum do navegador. Como sair: use o nome exato do output.
