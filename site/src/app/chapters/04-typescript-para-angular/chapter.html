Nele aparecem quatro ideias do TypeScript: um decorator (o @Component), uma classe, um modificador (protected readonly) e um genérico (o <number>). Ao final deste capítulo, você vai saber o papel de cada uma, e também escrever tipos e interfaces para os dados do Passaporte.

Uma tomada só aceita o plugue do formato certo. Se o formato não bate, você descobre na hora, antes de ligar o aparelho, e não depois de queimar alguma coisa.

Os tipos são o formato do plugue. Você diz que uma variável é um número, ou que um país tem nome, capital e população, e o TypeScript confere cada encaixe enquanto você escreve. O erro aparece no editor, sublinhado em vermelho, e não no navegador de quem usa o app.

Tipos básicos e inferência

string é texto, number é número (inteiro ou não), boolean é verdadeiro ou falso, e string[] é um array de textos. Na linha destacada não há tipo nenhum: o TypeScript deduz que capital é uma string pelo valor inicial. Isso se chama inferência, e é por causa dela que o código Angular quase não tem tipos escritos à mão nas variáveis.

Interfaces: o formato de um objeto

Uma interface descreve o formato de um objeto: quais propriedades ele tem e o tipo de cada uma. O ? em rating? diz que a nota é opcional: um país desejado ainda não tem nota. Esta interface, quase igual, vai ser a base do Passaporte.

Classes

Uma classe é um molde para criar objetos que juntam dados e ações. Todo componente Angular é uma classe.

Saída: Japão: 5 estrelas. As propriedades (country e rating) guardam os dados; os métodos (rate e describe) são as ações; o constructor roda uma vez, quando o objeto é criado com new. Dentro da classe, this quer dizer "este objeto". O readonly impede trocar o valor depois de criado, e o private esconde a propriedade de quem está fora da classe.

Sem modificador, uma propriedade é public: qualquer código pode ler. private deixa usar só dentro da classe. protected deixa usar dentro da classe e nas classes filhas.

No Angular, o template de um componente consegue ler propriedades protected, mas não private. Por isso o guia oficial recomenda protected para o que só o template usa, e é assim que você vai ver no Passaporte.

Genéricos: o tipo como parâmetro

O <T> é um tipo que se preenche depois. Array<string> é "um array de quê? de textos". A função first funciona com array de qualquer tipo e devolve um item do mesmo tipo. No Angular, você vai escrever genéricos como signal<number>(0): um signal de quê? de número.

Decorators: a etiqueta que dá superpoderes

O @Component(...) em cima da classe é um decorator. Sozinha, a classe Passport do início do capítulo é uma classe comum. O decorator cola nela uma etiqueta com informações extras (o seletor e o template) que transformam a classe num componente. Você vai escrever o seu primeiro componente no .
