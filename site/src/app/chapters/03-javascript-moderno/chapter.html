Promise, async e await

Buscar dados num servidor leva tempo. O JavaScript não fica parado esperando: ele entrega uma Promise, a promessa de um valor que vai chegar.

Você faz o pedido no balcão e recebe uma senha. A senha não é o lanche: é a promessa de que ele vai sair. Você espera chamarem o seu número e, aí sim, pega o lanche. A Promise é a senha; o await é esperar ser chamado.

Saída: Buscando... e, meio segundo depois, Brasil: Brasília. O await só pode ser usado dentro de uma função marcada com async. No Angular, você vai buscar dados de outro jeito, com ferramentas próprias, a partir do ; mas a ideia de "um valor que chega depois" é a mesma.

filter, map, find e o espalhamento sempre criam um array ou objeto novo. Já métodos como push, sort e splice alteram o próprio array.

Essa diferença importa porque, para o Angular perceber que um dado mudou, o jeito mais seguro é trocar o valor inteiro por um novo, em vez de mexer dentro dele. Por isso você vai ver muito [...lista, novo] e pouco push no Passaporte.
