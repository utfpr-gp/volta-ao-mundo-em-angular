O Passaporte tem seis países, e cada um ganha a sua página: /paises/JP para o Japão, /paises/PT para Portugal. Não são seis componentes nem seis rotas: é uma rota só, que lê o código do país direto do endereço.

Na lista, o nome de cada país vira um link para a página dele. E um botão sorteia outro destino e leva até ele. Ao final do capítulo, você vai saber criar rotas com parâmetros, receber o parâmetro num input() e navegar pelo código.

No aeroporto, todo viajante preenche o mesmo formulário. Ele já vem impresso, e só um espaço fica em branco: "número do passaporte". Ninguém imprime um formulário diferente para cada pessoa.

A rota paises/:code é esse formulário. A parte paises é o que já vem impresso; o :code é o espaço em branco, preenchido pelo endereço. E o mesmo componente atende todos os países.

Uma rota com espaço em branco

Os dois-pontos marcam um parâmetro: paises/:code combina com /paises/JP, /paises/PT, e com qualquer outro valor nesse lugar. Repare que paises e paises/:code são rotas diferentes: a primeira só combina com o endereço exato /paises.

O title também pode ser uma função. Ela recebe a rota e devolve o título; aqui, procura o país pelo código para a aba mostrar "Japão · Passaporte".

O mesmo componente, outro país

Indo de /paises/JP para /paises/PT, a rota é a mesma, e o Router não cria outro componente: ele só muda o valor do input. Por isso o país vem de um computed: quando o code muda, o país acompanha. Um valor copiado uma vez só, no ngOnInit, ficaria para trás (veja as armadilhas).

Navegar pelo código

O botão de sorteio não sabe para onde vai antes do clique, então não dá para ser um link. Ele pede ao Router, com inject(Router), para navegar. O navigate recebe os pedaços do endereço numa lista: ['/paises', 'JP'] vira /paises/JP. A regra: use link quando o destino é um lugar conhecido; navegue pelo código quando o destino depende de uma ação.

E, na lista, o nome de cada país virou um link, montado com a mesma lista de pedaços:

Por padrão, o routerLinkActive considera o link ativo quando o endereço atual começa com o dele: /paises/JP começa com /paises. É o que se espera de um menu. Para exigir o endereço exato, use [routerLinkActiveOptions]="{{ '{' }} exact: true {{ '}' }}".

O que muda na tela: clique em "Japão" na lista: a página do Japão abre, e a aba diz "Japão · Passaporte". Clique em "Sortear outro destino" algumas vezes e veja o endereço mudar. Experimente /paises/xx na barra de endereço.

Sem essa opção, o Router não entrega o parâmetro ao input, e o input obrigatório fica sem valor. A tela fica em branco. Como sair: provideRouter(routes, withComponentInputBinding()).

O parâmetro só chega ao input de mesmo nome. Como sair: use o mesmo nome nos dois lugares.

O componente não é recriado quando só o parâmetro muda, então o ngOnInit não roda de novo. Como sair: derive o que depende do parâmetro com computed, lendo o input.
