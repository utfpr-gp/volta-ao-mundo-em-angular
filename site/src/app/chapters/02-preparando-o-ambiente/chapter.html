O npm: a loja de pacotes

Junto com o Node.js vem o npm, o gerenciador de pacotes. Um pacote é um código pronto que alguém publicou para todo mundo usar. O Angular inteiro é distribuído assim: cada parte dele é um pacote no npm. Pense numa loja de aplicativos do celular, só que para código: você pede pelo nome, e o npm baixa e instala.

Todo projeto Angular tem um arquivo package.json, a lista de compras do projeto: ele diz de quais pacotes o projeto precisa e em que versão. Quando você roda npm install, o npm lê essa lista e baixa tudo para a pasta node_modules.

Essa pasta costuma ser enorme, com milhares de arquivos, e nunca vai para o Git: qualquer pessoa recria a pasta rodando npm install de novo. Você vai ver os dois de perto no .

Qual versão do Node.js?

O Node.js lança versões o tempo todo, mas só algumas são LTS, de "suporte de longo prazo": versões estáveis que recebem correções por anos. Para estudar e para trabalhar, use sempre uma versão LTS. O Angular 22 aceita o Node.js 22.22.3 ou mais novo da linha 22, o 24.15 ou mais novo da linha 24, e a linha 26.

O editor: VS Code com a extensão do Angular

Você pode escrever código em qualquer editor, mas o Visual Studio Code (VS Code) é gratuito, roda em Windows, macOS e Linux e tem a extensão oficial do time do Angular, a Angular Language Service. Com ela, o editor entende os templates: completa nomes enquanto você digita, aponta erros antes de rodar e leva você da tela para o código com um clique. O VS Code também tem um terminal embutido, que abre com Ctrl + ' no teclado brasileiro (a tecla à esquerda do 1) ou pelo menu Terminal › Novo terminal.

E o Git?

O Git guarda o histórico do seu código, como pontos de salvamento num jogo, e é como o código chega ao GitHub. Ele vai ser necessário no fim do livro, para publicar o Passaporte. Git é um assunto à parte, que este livro não ensina; se ainda não usa, o livro gratuito Pro Git, em português, é um ótimo começo.

Em inglês, a mesma mensagem diz command not found; no Windows, ela diz que o nome não é reconhecido como um comando. Em todos os casos, o terminal procurou um programa chamado node e não achou.

Como sair, do mais comum ao menos comum:

  1. O terminal foi aberto antes da instalação. Cada terminal lê a lista de lugares onde procurar programas só quando abre. Feche todas as janelas do terminal (e do VS Code) e abra de novo.
  2. O Node.js não foi instalado. Refaça os passos da instalação.
  3. Erro de digitação. nodejs ou Node, com maiúscula, não funcionam: é node.

Você tem um Node.js instalado, mas de uma versão anterior à que o Angular 22 aceita. É comum em computadores de laboratório ou em quem instalou o Node.js há alguns anos.

Como sair: instale a versão LTS atual, como nos passos acima, e confira com node -v. Se você usa o nvm, basta nvm install --lts.
