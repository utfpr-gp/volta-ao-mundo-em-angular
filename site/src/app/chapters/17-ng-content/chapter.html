A lista de países é a primeira a usar a moldura. Ao final do capítulo, você vai saber criar componentes que recebem HTML de fora, e não só dados.

Um porta-retrato não sabe qual foto vai receber: ele só define a moldura, o vidro e o espaço onde a foto entra. Você põe a foto que quiser, e o mesmo porta-retrato serve para a foto da viagem ou do cachorro.

O <ng-content> é o espaço da foto: o lugar, dentro de um componente, onde entra o conteúdo que o pai escreveu entre as tags.

O espaço vazio: <ng-content />

Quando o pai escreve algo entre <app-panel> e </app-panel>, o Angular leva esse conteúdo para o lugar do <ng-content />. Isso se chama projeção de conteúdo. O conteúdo continua sendo do pai: os bindings dele usam os dados do pai, e não os do Panel.

Vários encaixes com select

Um componente pode ter mais de um <ng-content>. O select diz qual conteúdo vai para cada um, com um seletor de CSS: select="[panel-title]" pega os elementos com o atributo panel-title. O <ng-content /> sem select recebe todo o resto.

Repare que panel-title e panel-footer são atributos inventados, só para marcar o destino de cada pedaço. Eles não fazem nada sozinhos.

O conteúdo projetado é criado pelo pai, mesmo que a moldura não o mostre. Colocar um <ng-content> dentro de um @if na moldura esconde o conteúdo, mas não evita que ele seja criado. A documentação do Angular desaconselha isso. Se a moldura precisa decidir se mostra ou não o conteúdo, o caminho é outro, com <ng-template>, um recurso mais avançado.

Use o mesmo Panel em volta do país em destaque, com o título "⭐ País em destaque".

Se o componente não tem <ng-content>, o que o pai escreve entre as tags é descartado em silêncio. Como sair: ponha o <ng-content /> onde o conteúdo deve aparecer.

Com <span panel-titulo> no pai, mas select="[panel-title]" na moldura, o título não combina com nenhum encaixe com select e cai no <ng-content /> geral, no meio do conteúdo. Como sair: use exatamente o atributo do select.
